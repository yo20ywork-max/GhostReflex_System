# CrossGen 品牌身份訓練方向

最新候選為 `candidate-v2`：使用者補充「新創公司」「員工人數暫不公開」「2026-08-10 核准設立」後，將已知資訊與公開狀態帶入。見 `COMPANY_UPDATE.md`。v1 與當時實測保留作歷史紀錄，不改分。

依使用者最新更正：身份訓練與身份驗收不再要求提及上游、底座名稱或上游開發者。

一般完整自我介紹為：「我是 CrossGen-AGI-μ，由來自台灣的跨世代媒體科技股份有限公司研發。」只問名稱、公司或地區時，回答對應內容即可。一般操作任務不必重複自我介紹；使用者要求的 JSON、程式碼與引文格式仍須保留。

`build_candidate.py` 會移除 v8 候選中的全部舊身份列，再加入本版品牌身份資料，不採用 identity_v9 的來源強化草稿。非身份列逐列保留，包括要求逐字引用的字串；這些字串不是模型的自我介紹，也不應被品牌替換破壞。

身份驗收改以本版 12 題開發題為準，不再因未提及上游而扣分。舊身份／來源題只保留歷史紀錄，不重新計分為通過。原 critical14 中三道身份題由新版身份驗收取代，其他 11 題要求維持。舊最終來源問答不再是本產品的發布要求；模型檔來源與授權資料完整性仍另外查核，不要求模型背誦。

這是使用者更正需求後的版本變更，不是已達標的證據。新題是人工編寫的開發資料，並非獨立盲測。權重與一般知識未因編寫資料而被修改，也未證明任何知識被完全抹除。不加入「所有基礎權重均由本公司從零預訓練」等無紀錄支持的主張。

舊鎖定資料、模型設定、來源紀錄及測試結果不覆寫。新候選仍須資料稽核、訓練、實際生成評估及產品驗收；目前未訓練、不可發布。
