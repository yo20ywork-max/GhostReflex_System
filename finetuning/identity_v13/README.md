# 下一版訓練資料：準備中

本版仍沿用既定產品目標與發布門檻，沒有啟動新訓練，也沒有把權重身分失敗改成只測system。

`candidate-v1` 保留原1633筆，加上64筆既有訓練題的無品牌提示變體與24筆新題，共1721筆。身份類120筆只有56個獨立題目，不能說成120個不同情境。88筆新增輸入的system沒有提供產品事實；公司、日期與員工公開狀態要求不變。

`FULL_DATA_AUDIT.json` 已對全部1721筆train及385筆dev使用實際訓練tokenizer核對：沒有完全相同的train/dev題目，沒有同輸入不同答案的直接衝突，沒有超過12288 token，assistant-only遮罩與來源metadata隔離通過。這不保證語意獨立或資料品質全部通過。歷史48筆本來已有正確日期與中性system，不能把歷史失敗也一概歸因於身分提示。

`action-additions-v1` 是另行準備的28筆操作資料，尚未合入candidate-v1：20筆計畫、4組順序正反對照，涵蓋路徑與文字內容引用、可見文字與CSS、先判斷副本存在再決定是否讀取，以及等待成功前不可先讀結果。它們來自4個新寫工作情境，不冒充28種獨立任務；未搬入已知開發題答案。

- 20筆計畫通過實際parser。
- 檔案計畫以真實工具執行16個情境，含條件兩分支、Unicode/換行/字面引用、位元組保留、讀回及既有副本不開來源，全部通過。這是人工提供計畫的資料驗證，非模型生成成績。
- 8筆瀏覽器計畫以本機DOM執行等待及讀取成功；另8個不存在selector的對照證實工具可能回報hidden成功卻尚未滿足真正等待條件，資料驗證可辨識這種差異。
- 28筆實際token化與metadata隔離通過，最長7036 token。
