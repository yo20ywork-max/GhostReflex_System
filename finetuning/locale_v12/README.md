# 台灣用語與任務語意

目前有效候選是 `candidate-v2`：40 筆訓練、24 筆開發題。範圍包括台灣用語改寫、口語目的地、文字辨識錯字、否定與後續更正、檔名／UI 標籤逐字保留、JSON 路徑、物理質量與產品品質，以及有歧義／已明確指定的選檔指令。

這是合成文字資料，沒有錄音或真實 ASR 對齊資料。訓練與開發題沒有相同 prompt，但詞彙與題型共享；不是盲測，也不證明任意口語、真實語音或螢幕操作都能完成。沒有用此資料替換既有 locale、ASR、工具執行、歷史或其他發布門檻。

## 訓練方向與隔離

新增訓練情境包含肯定執行、撤回、條件等待、明確選檔與需要澄清的對照，避免只學到一律拒絕或一律詢問。開發題保留在 dev，未把失敗題及答案複製到 train。修正文字用語與逐字保留資料分開出題，禁止用全域字詞替換修補模型輸出。

來源身分、授權與出處只存內部側檔；train/dev 不含頂層 source／attribution／license。`build_context_candidate.py` 使用下一版訓練程式的實際 tokenizer，逐筆注入不同的來源中繼資料，驗證 ids、labels 與 prefix 完全相同。64 筆均通過 Unicode roundtrip、assistant-only loss mask 與中繼資料隔離檢查。這不代表既有權重忘記所有来源，也不把來源身分加入模型應答要求。
