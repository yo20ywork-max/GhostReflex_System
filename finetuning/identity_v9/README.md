# 身份與上游角色資料草稿

草稿通過群組分隔、與原 train/dev 精確需求不重複、原版 tokenizer 逐字還原與 assistant-only 遮罩檢查，最長 208 tokens。沒有開啟最終封存題。新增 dev 與 train 共享角色概念，不是完全獨立盲測。
